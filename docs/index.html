The suite

Everything an agent needs, nothing it shouldn't have

Sensitive actions pass through an explicit permission system. Your keys live in an encrypted vault. No account, no telemetry, no cloud.

⌥

Bring your own AI

OpenAI, Anthropic, Gemini, OpenRouter, Ollama, or any OpenAI-compatible endpoint. Switch providers without losing your workflow.

✦

4,427+ skillsBUNDLED

Coding, debugging, DevOps, databases, security, automation and more — searched and loaded only when relevant.

⌸

Permission system

Shell, writes, deletes, network, git pushes — every sensitive action is allowed once, scoped, or denied. Deny always wins.

⏺

True in-app terminalNEW

Persistent working directory, ANSI colors, command history, Ctrl+C — and every agent command inspectable alongside yours.

🌐

Tool call languageNEW

Pick the language your agent narrates in — 18 languages or Auto. Code and commands stay verbatim.

⚿

Encrypted vault

API keys sealed with scrypt key derivation and AES-256-GCM. The decryption key never leaves service memory.

⎘

Safe file editing

Hash-checked edits reject stale writes, and every change lands as a restorable checkpoint.

⌂

Local first

The service binds to 127.0.0.1:4317. Your projects never leave your machine — pair it with Ollama for fully local operation.
